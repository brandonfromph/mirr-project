### Section G: Add temporal lowering algorithm figure

**Source:** Extracted from `src/temporal/compiler.rs` — `compile_guard()` (lines 78–171), `SHIFT_REGISTER_THRESHOLD = 16` (line 27), `ResourceEstimator::choose_optimal_strategy()` (lines 298–306)

**Insert after:** The temporal compilation description

**LaTeX content:**

```latex
\begin{figure}[t]
\footnotesize
\begin{algorithmic}[1]
\Require Guard $g$ with condition $c$ and delay $N$ cycles
\Ensure Compiled hardware: shift register, counter, or complex gate
\Statex
\Function{CompileGuard}{$g$}
  \If{$c$ is a simple condition (signal, threshold, or comparison)}
    \If{$N \leq T_{\mathrm{sr}}$} \Comment{$T_{\mathrm{sr}} = 16$}
      \State \Return \Call{ShiftRegister}{$g.c,\ N$}
        \Comment{$N$ flip-flops, $O(N)$ area}
    \Else
      \State \Return \Call{Counter}{$g.c,\ N$}
        \Comment{$\lceil\log_2 N\rceil{+}1$ flip-flops, $O(\log N)$ area}
    \EndIf
  \ElsIf{$c = c_L \mathbin{\texttt{op}} c_R$ where $\texttt{op} \in \{\texttt{\&\&}, \texttt{||}\}$}
    \State $h_L \gets$ \Call{CompileGuard}{$(g.\mathrm{name\_L},\ c_L,\ N)$}
    \State $h_R \gets$ \Call{CompileGuard}{$(g.\mathrm{name\_R},\ c_R,\ N)$}
    \State \Return \Call{ComplexGate}{$h_L \mathbin{\texttt{op}} h_R$}
      \Comment{logic gate combining sub-guards}
  \Else
    \State \textbf{reject} ``unsupported condition form''
  \EndIf
\EndFunction
\end{algorithmic}

\smallskip
\noindent
The threshold $T_{\mathrm{sr}} = 16$ is the crossover point where
counter-comparator area ($\lceil\log_2 N\rceil + 1$ flip-flops) becomes
smaller than shift register area ($N$ flip-flops). For $N = 100$,
the counter uses 8 bits vs.\ 100 registers---a 12$\times$ reduction.
Complex boolean guards are decomposed recursively, with each leaf
independently selecting the optimal strategy.

\caption{Adaptive temporal guard compilation algorithm.
Implementation: \texttt{temporal/compiler.rs} (425 lines).}
\label{fig:temporal-algo}
\end{figure}
```

### Section H: Explain fir_filter anomaly in synthesis table

**Source:** `examples/fir_filter.mirr` has a 1-cycle guard (`for 1`), which compiles to a combinational passthrough — the shift register has length 1, so the guard output is just the input delayed by one register. But since the guard fires on the same cycle, the FIR multiply-accumulate (MAC) logic is purely combinational.

**Insert as:** A footnote or paragraph immediately after the synthesis table

**Text:**

```latex
The \texttt{fir\_filter} module exhibits 1,650 cells but zero
flip-flops because its single guard specifies a 1-cycle delay,
which the temporal compiler lowers to a combinational passthrough
(the shift register degenerates to a wire). The large cell count
reflects the FIR multiply-accumulate datapath---four 16-bit
multipliers and a 3-stage adder tree---implemented entirely in
combinational logic. This is consistent with the compilation
strategy: guards with $N = 1$ produce no sequential elements.
```
