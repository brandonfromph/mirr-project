### B1. Constraint.v — 3 theorems (Easy-Medium)

**File:** `proofs/width/Constraint.v`

**`add_sound` (T4, line 77):** If `a < 2^(max a b)` and `b < 2^(max a b)`, then
`a + b < 2^(S(max a b))`. Strategy: `rewrite Nat.pow_succ_r; lia.`

**`mul_sound` (T5, line 85):** If `a < 2^wa` and `b < 2^wb`, then `a*b < 2^(wa+wb)`.
Strategy: `rewrite Nat.pow_add_r; apply Nat.mul_lt_mono_nonneg; lia.`

**`shift_sound` (T7, line 102):** If `a < 2^wa`, then `a * 2^s < 2^(wa+s)`.
Strategy: `rewrite Nat.pow_add_r; apply Nat.mul_lt_mono_pos_r; [apply Nat.pow_pos_nonneg|]; lia.`

### B2. MinBits.v — 3 theorems (Medium)

**File:** `proofs/width/MinBits.v`

**WARNING:** Agent 1 flagged that `min_bits_pow2` may be FALSE as stated.
Must verify by computation before attempting proof. If false, correct the statement.

**`min_bits_correct` (T13, line 40):** `v < 2^(min_bits v)`.
Strategy: Strong induction on `v` via `lt_wf_ind`. Step: `v > 0` gives
`min_bits v = 1 + min_bits (div2 v)`. IH gives `div2 v < 2^(min_bits(div2 v))`.
Then `v <= 2 * div2 v + 1 < 2^(1 + min_bits(div2 v)).`

**`min_bits_minimal` (T13b, line 46):** `fits v w -> min_bits v <= w`.
Strategy: Strong induction on `v`. If `fits v w`, then `v < 2^w`.
For `v > 0`: `div2 v < 2^(w-1)`, so `fits (div2 v) (w-1)`.
IH: `min_bits (div2 v) <= w-1`, hence `min_bits v = 1 + min_bits(div2 v) <= w`.

### B3. SCC proofs — 2 theorems (Medium)

**Files:** `proofs/width/SCC/Classify.v`, `proofs/width/SCC/Nonexpansive.v`

**`nonexpansive_bounded` (line 70):** If `classify_scc` returns `Nonexpansive`, then
no binary node in the SCC uses an expansive operator. Strategy: Apply `classify_sound`
(already proven) to get `has_expansive = false`. Induction on component list.

**`nonexpansive_max_bound` (line 66):** A nonexpansive constraint's output width is
bounded by `fold_right Nat.max 0 st`. Strategy: Case analysis on 5 nonexpansive
constraint types. Auxiliary lemma: `lookup st i <= fold_right Nat.max 0 st`.

### B4. Encoding.v — 6 theorems (Medium, all same pattern)

**File:** `proofs/rspu/Encoding.v`

All 6 are bitfield extraction roundtrips on `Z`. The pattern is identical:

```coq
(* Core strategy for all 6: *)
Theorem field_roundtrip : forall ... ,
  extract_field (pack_format ...) = field.
Proof.
  intros. unfold extract_field, pack_format, extract_bits.
  (* Z.land (Z.shiftr (Z.lor (Z.shiftl a offset) b) offset) mask = a *)
  rewrite Z.shiftr_lor, Z.shiftr_shiftl_l; [| lia].
  rewrite Z.land_lor_distr_l.
  (* The shifted-down payload vanishes under the mask *)
  rewrite Z.land_ones; [| lia].
  rewrite Z.mod_small; lia.
Qed.
```

Specific theorems: `opcode_roundtrip`, `r_type_dst_roundtrip`, `r_type_src1_roundtrip`,
`r_type_funct_roundtrip`, `i_type_imm_roundtrip`, `s_type_imm_roundtrip`.

A shared auxiliary lemma `bitfield_extract_roundtrip` would make 5 of the 6 nearly
free once proven for the first case.

### B5. Monotone.v — 2 theorems (Medium, depends on B1)

**File:** `proofs/width/Monotone.v`

**`monotonicity` (T2, line 49):** If `s1 ⊑ s2`, then evaluating any constraint against
both states preserves the output node and the width grows. Strategy: `destruct c` for
all 10 constraint variants. Each case: invert `Some` equalities, apply `Nat.max_le_compat`
or `Nat.add_le_mono` using `s1 ⊑ s2` (pointwise `<=`).

**`evaluate_monotone` (T3, line 74):** `st ⊑ apply_constraints cs st`.
Strategy: Induction on `cs`. Base: `state_le_refl`. Step: Show conditional `update`
only increases. IH + transitivity.

### B6. Solver.v — 2 theorems (Hard, depends on B5)

**File:** `proofs/width/Solver.v`

**`solver_terminates` (T1, line 62):** The hardest theorem. The iterative solver reaches
a fixpoint within `MAX_WIDTH * |st|` rounds. Strategy: Potential function
`Phi(st) = SUM(MAX_WIDTH - lookup st i)`. Each non-trivial round strictly decreases `Phi`.
Since `Phi >= 0` and `Phi <= solver_budget`, termination follows by well-founded induction.
Requires `evaluate_monotone` (T3) to show widths only grow.

**`fixpoint_least` (T9, line 80):** Starting from zero, the solver computes the least
fixpoint. Strategy: Induction on fuel. At each step, `solver_round cs st_n ⊑ st_fix`
by monotonicity (T2) since `st_n ⊑ st_fix`.

### B7. Integration.v — capstone (depends on ALL above)

**File:** `proofs/width/Integration.v`

**`e2e_solver_sound` (line 61):** The capstone theorem composing T1-T9. Given a
well-formed flat-node array and zero-initialized state, the solver produces a fixpoint
that is pointwise `>=` the initial state. Strategy: Conjunct 1 from T1
(solver_terminates). Conjunct 2 from T3 (evaluate_monotone) applied across iterations.
This should be short (~15 lines) once dependencies are proven.
