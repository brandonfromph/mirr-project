TYPE-001 is the mandatory first move. Everything else chains from it.


Introduce a semantic type-checking pass (`src/typeck/mod.rs`) that runs between
validation and simplification in the MIRR pipeline. The current pipeline validates
names and references but never checks type compatibility — assigning a `bool` to a
`u16` signal, or applying `&&` to unsigned operands, produces no error.

This campaign closes that gap with 16 type rules, 7 unique error codes (E601-E607),
and a new `MirrError::TypeError` variant.

TYPE-001 is the mandatory foundation for all Phase 7 work: dependent types, linear
types, effect systems, higher-order functions, and Rocq proofs all require a type
system to exist before they can extend it.

## Philosophy Gate

All four principles passed:
- **Generative power of three:** No new constructs. Signal/Guard/Reflex triad preserved.
- **NASA P10:** Bounded iteration (MAX_EXPR_NODES = 512). No recursion. No unsafe.
- **Hardware-synthesizable:** Type checker only rejects; does not add expressiveness.
- **Properties don't affect hardware:** Properties type-checked same as other expressions.

## Type Rules

| Rule | Context | Types | Result | Error if violated |
|------|---------|-------|--------|-------------------|
| T1 | Assignment `target = value` | target.ty vs typeof(value) | Must match (bool→u1 promotion allowed) | E602 |
| T2 | Arithmetic `+`, `-`, `*` | Unsigned(N) op Unsigned(M) | Unsigned(max(N,M)) | — |
| T3 | Arithmetic `+`, `-`, `*` | Bool involved | **Error** | E603 |
| T4 | Shift `<<`, `>>` | Unsigned(N) op Unsigned(M) | Unsigned(N) | E603 if bool |
| T5 | Comparison `<`, `<=`, `>`, `>=` | Unsigned(N) op Unsigned(M) | Bool | — |
| T6 | Equality `==`, `!=` | Same category | Bool | E606 if cross-category |
| T7 | Ordering `<`, `>`, `<=`, `>=` | Bool involved | **Error** | E605 |
| T8 | Logical `&&`, `\|\|` | Bool op Bool | Bool | — |
| T9 | Logical `&&`, `\|\|` | Unsigned involved | **Error** | E604 |
| T10 | Bitwise `^` | Same type | Same type | E607 if mismatched |
| T11 | Unary `!` on Bool | Bool | Bool | — |
| T12 | Unary `!` on Unsigned | Unsigned(N) | Unsigned(N) | — |
| T13 | `prev(signal, delay)` | — | typeof(signal) | — |
| T14 | Guard condition | — | Must be Bool | E601 |
| T15 | Literal true/false | — | Bool | — |
| T16 | Literal integer N | — | Unsigned(min_bits(N)) | — |

## Error Codes

| Code | Message pattern |
|------|----------------|
| E601 | `[E601] Guard '{name}' condition must be bool, got {ty}.` |
| E602 | `[E602] Assignment to '{target}' ({target_ty}): expression type {expr_ty} is not compatible.` |
| E603 | `[E603] Operator '{op}' requires unsigned operands, got {left_ty} and {right_ty}.` |
| E604 | `[E604] Operator '{op}' requires bool operands, got {left_ty} and {right_ty}.` |
| E605 | `[E605] Ordering operator '{op}' cannot compare {left_ty} and {right_ty}.` |
| E606 | `[E606] Equality operator '{op}' cannot compare {left_ty} and {right_ty}.` |
| E607 | `[E607] Operator '^' (xor) requires matching types, got {left_ty} and {right_ty}.` |
