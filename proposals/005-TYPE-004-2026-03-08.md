## Summary

Enforce that each writable signal (Output or Internal) has exactly one writer
reflex at compile time. Adds `validate_signal_ownership` to semantic validation,
emitting [E216] for any signal written by more than one reflex. Pattern-expanded
reflexes are included in the check (using origin tags for diagnostics).

## Philosophy Gate

- **Generative power of three.** Signal/Guard/Reflex unchanged. PASS.
- **NASA P10.** Single bounded pass over reflexes. No recursion. PASS.
- **Hardware-synthesizable.** Single-writer = no bus contention. PASS.
- **Properties don't affect hardware.** Properties excluded from ownership check. PASS.

## Error Codes

| Code | Message pattern |
|------|----------------|
| E216 | `[E216] Signal '{sig}' has multiple writers: reflex '{r1}' and reflex '{r2}'.` |
