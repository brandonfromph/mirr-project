**Proposal #:** 013

**Depends on:** SPAN-001 (#011), ERR-001 (#012)

---

## Motivation

The MIRR compiler emits SystemVerilog through `--emit verilog`, but the output is **not synthesizable**. A TMR sensor fusion controller (28 signals, 13 guards, 15 reflexes, 7 properties) exposed 5 critical bugs and 3 medium-severity issues that would each independently prevent synthesis or produce incorrect hardware.

The generated `.sv` compiles through all 9 MIRR pipeline stages but cannot be fed to Vivado, Quartus, or Yosys — the three most common FPGA synthesis tools — without manual correction. This means the Verilog emitter, while structurally complete, is **a demo, not an engineering tool**.

**Current state:** Generated SystemVerilog looks plausible but contains:

```systemverilog
// BUG 1: Multi-guard uses OR instead of AND
// MIRR source says: on g1 and g2 { ... }
// Emitter produces:
if (g1_out || g2_out) safety_shutdown = 1'b1;  // WRONG — should be &&

// BUG 2: 1-cycle shift register is malformed
logic [0:0] a_healthy_sr;
a_healthy_sr <= {a_healthy_cond, a_healthy_sr[0:1]};  // [0:1] invalid on [0:0]

// BUG 3: No default assignments — creates latches
always_comb begin
  if (guard_out) signal = value;  // What happens when guard is inactive? LATCH.
end

// BUG 4: clk referenced but never declared as a port
always_ff @(posedge clk or negedge rst_n) begin  // clk is undeclared
```

**Target state:** Every `--emit verilog` output passes Yosys `read_verilog -sv` lint, synthesizes to gate-level netlist, and optionally emits FPGA project scaffolding (constraints template, testbench, build script).

**Future campaigns (not in this proposal):**
- FPGA-002: BRAM inference, DSP inference, vendor-specific IP instantiation
- FPGA-003: Formal verification integration (SymbiYosys runner)

## Bugs Found

| # | File:Line | Bug | Severity | Fix |
|---|-----------|-----|----------|-----|
| B1 | `verilog.rs:232` | Multi-guard reflexes join with `\|\|` (OR) instead of `&&` (AND). MIRR `on g1 and g2` means both must be active. | **Critical** | Change `" \|\| "` to `" && "` |
| B2 | `verilog.rs:168` | 1-cycle shift register emits `name_sr[0:1]` — invalid range on `logic [0:0]`. | **Critical** | Special-case `delay_cycles == 1`: emit `assign _out = _cond;` (no flip-flop) |
| B3 | `verilog.rs:226` | `always_comb` blocks have no default assignments before `if`. Synthesis infers latches. | **Critical** | Emit `signal = '0;` defaults before the `if` block |
| B4 | `verilog.rs:95-98` | `clk` and `rst_n` used in `always_ff` / SVA but never declared as ports. | **Critical** | Auto-inject `input logic clk, input logic rst_n` into port list when temporal guards exist |
| B5 | `verilog.rs:175,208` | Guard `_out` wires assigned via `assign` but never declared with `logic`. | **High** | Emit `logic name_out;` before the `assign` statement |
| B6 | `firrtl.rs:213` | FIRRTL emitter has the same multi-guard OR bug as verilog.rs. | **Critical** | Change `or()` to `and()` in firrtl.rs multi-guard join |
| B7 | `firrtl.rs:219-224` | FIRRTL `when` blocks have no `else` (same latch issue as B3). | **Medium** | Add `else : connect signal, UInt(0)` default |
| B8 | `emit_verilog_tests.rs:101` | Test `sv_multi_guard_reflex_uses_or` pins the wrong behavior — asserts `\|\|`. | **Medium** | Update test to assert `&&` after fixing B1 |

## Proposal

### Section A: Critical Bug Fixes — `src/emit/verilog.rs` (edit)

**Step 1: Multi-guard AND fix (B1)**

```rust
// Before (line 232):
parts.join(" || ")

// After:
parts.join(" && ")
```

**Step 2: 1-cycle shift register fix (B2)**

Add special case before line 154:

```rust
if sr.delay_cycles == 1 {
    // 1-cycle guard: purely combinational, no shift register needed.
    out.push_str(&format!("  logic {}_cond;\n", sr.name));
    out.push_str(&format!("  assign {}_cond = {};\n",
        sr.name, emit_condition_expr(&sr.condition_kind)));
    out.push_str(&format!("  assign {} = {}_cond;\n\n",
        sr.output_signal, sr.name));
    return;
}
```

**Step 3: Default assignments in `always_comb` (B3)**

Insert default assignments between `always_comb begin` and the `if` blocks:

```rust
out.push_str("  always_comb begin\n");
// NEW: emit defaults
for a in &r.assignments {
    out.push_str(&format!("    {} = '0;\n", a.target));
}
for a in &r.assignments {
    // existing if (guard_cond) ...
}
```

**Step 4: Auto-inject `clk` and `rst_n` ports (B4)**

Replace `emit_port_list()` (lines 95-98). When temporal guards exist, inject:

```systemverilog
input  logic        clk,
input  logic        rst_n,
```

Skip injection if the user's MIRR source already declares signals named `clk` or `rst_n`.

**Step 5: Declare guard `_out` wires (B5)**

Before each `assign name_out = ...`, emit `logic name_out;`.

### Section B: FIRRTL Bug Fixes — `src/emit/firrtl.rs` (edit)

**Step 6: Multi-guard AND fix (B6)**

Change line 213 from `or()` to `and()`:

```rust
// Before:
expr = format!("or({}, {}_out)", expr, r.guard_names[i]);

// After:
expr = format!("and({}, {}_out)", expr, r.guard_names[i]);
```

**Step 7: Default `else` clause (B7)**

After each `when guard_cond : connect target, value`, add:

```firrtl
else :
  connect target, UInt(0)
```

### Section C: FPGA Target Infrastructure — new `src/emit/fpga_target.rs` (~60 lines)

Enum representing supported FPGA families:

```rust
pub enum FpgaTarget {
    Xilinx7,       // Artix-7, Kintex-7, Zynq-7000
    XilinxUS,      // UltraScale / UltraScale+
    IntelCyclone,  // Cyclone V, Cyclone 10
    LatticeIce40,  // iCE40 (Yosys + nextpnr flow)
    Generic,       // No vendor-specific features
}
```

Methods: `clock_primitive()`, `constraint_extension()` (`.xdc` vs `.sdc`), `build_tool()` (`vivado` vs `quartus_sh` vs `nextpnr-ice40`).

### Section D: Input Synchronizer Chains — `src/emit/verilog.rs` (edit, +~30 lines)

When `--sync-stages N` (N > 0, default 2), emit for each `input` signal (except `clk` and `rst_n`):

```systemverilog
// 2-stage synchronizer for metastability protection
logic [1:0] sensor_a_sync;
always_ff @(posedge clk or negedge rst_n) begin
  if (!rst_n)
    sensor_a_sync <= '0;
  else
    sensor_a_sync <= {sensor_a[15:0], sensor_a_sync[1]};
end
wire [15:0] sensor_a_s = sensor_a_sync[0];  // use _s suffix internally
```

Internal logic then uses `sensor_a_s` instead of `sensor_a`.

**Flag:** `--sync-stages 0` disables synchronizer emission (for testbench/sim use).

### Section E: Auto-Testbench — new `src/emit/testbench.rs` (~100 lines)

Generates `module_name_tb.sv` that:

1. Instantiates the MIRR module with port connections
2. Generates a clock: `initial clk = 0; always #5 clk = ~clk;`
3. Drives all inputs to zero, then to max range
4. Asserts all non-cover properties after 100 cycles
5. Reports pass/fail count

Emitted via `--emit testbench` or `--emit verilog --testbench`.

### Section F: Constraint/Build Scaffolding — new `src/emit/fpga_scaffold.rs` (~120 lines)

**For `--target xilinx-7` or `--target xilinx-us`:**

Emits `module_name.xdc`:
```tcl
## Auto-generated from MIRR — fill in pin assignments
create_clock -period 10.000 -name clk [get_ports clk]
# set_property PACKAGE_PIN {PLACEHOLDER} [get_ports clk]
# set_property IOSTANDARD LVCMOS33 [get_ports clk]
## ... one line per port ...
```

Emits `build.tcl`:
```tcl
create_project tmr_sensor_fusion ./build -part xc7a35tcpg236-1 -force
add_files tmr_sensor_fusion.sv
add_files -fileset constrs_1 tmr_sensor_fusion.xdc
launch_runs synth_1 -jobs 4
wait_on_run synth_1
launch_runs impl_1 -to_step write_bitstream -jobs 4
wait_on_run impl_1
```

**For `--target intel-cyclone`:** Emits `.sdc` + `.qsf`.

**For `--target lattice-ice40`:** Emits `.pcf` + `build.sh` (Yosys + nextpnr).

Emitted via `--emit scaffold` or alongside verilog with `--target`.

### Section G: CLI Integration — `src/bin/mirr-compile.rs` (edit)

Add flags:
- `--target <family>` — Select FPGA target (default: `generic`)
- `--sync-stages <N>` — Input synchronizer stages (default: `2`, `0` to disable)
- `--testbench` — Also emit a self-checking testbench
- `--scaffold` — Also emit constraint template and build script
