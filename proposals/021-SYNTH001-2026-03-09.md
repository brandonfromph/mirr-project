## Motivation

The MIRR compiler emits SystemVerilog, but that output has never been validated through a real synthesis tool. The paper (line 833-834) says "silicon synthesis and FPGA validation are future work." With oss-cad-suite installed (Yosys 0.63+87), we can close this gap.

**The problem:** `--emit verilog` includes SVA `assert property` / `assume property` / `cover property` blocks inline with RTL. Yosys cannot parse SVA, causing `syntax error, unexpected '@'` at the first `assert property (@(posedge clk) ...)` block. This affects 9 of 14 examples (every module with `property` declarations).

**Evidence from audit:** `shift_register_guard.mirr` (0 properties) synthesizes cleanly to 15 cells. `tmr_sensor_fusion.mirr` (7 properties) fails at line 255 with `unexpected '@'`.

**The solution:** Add `--strip-sva` flag for synthesis-clean RTL output, add `--sva-file` for separate SVA bind file emission, validate all compilable examples through Yosys, and write integration tests.
