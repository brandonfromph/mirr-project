# SEM-001 — Assign Unique Error Codes to All Semantic Diagnostics (E2xx)

**Proposal #:** 001
**Campaign ID:** SEM-001
**Date:** 2026-03-08
**Status:** SIGNED and EXECUTED

## Summary

Assigned unique error codes E201-E215 to all 15 semantic diagnostic sites across
`src/validation/semantic.rs` (11 sites) and `src/expand/mod.rs` (4 sites). Previously,
every semantic error shared a single `[E200]` prefix, making individual errors
unidentifiable. The E5xx width subsystem already followed the correct pattern
(E500-E511), and this campaign extended it to E2xx.

## Philosophy Gate

All four principles passed. No triads broken. No new constructs. Diagnostic-only change.
