# SITE-001 — Documentation & Website Cleanup Campaign

**Proposal #:** 009
**Campaign ID:** SITE-001
**Date:** 2026-03-09
**Status:** SIGNED
**Scope:** Documentation and website (README, 7 docs, _config.yml, ci.yml)

---

## Motivation

After eight executed campaigns (SEM-001 through DOC-001), the public-facing documentation
has accumulated three categories of problems:

| # | Problem | Impact |
|---|---------|--------|
| 1 | README header has 5 static badges + 5 navigation links before any content | First impression is a wall of shields, not the project description |
| 2 | Website sidebar shows only 5 of 7 published pages (`rspu-reference.md` and `type-system.md` lack front matter) | Two major reference docs are invisible in navigation |
| 3 | No cross-links between docs — each page is a dead end | Users must return to home page to navigate |
| 4 | README documentation table missing Type System and R-SPU Reference | Two shipped features undiscoverable from README |
| 5 | CI workflow missing skip for `flight_controller_signed.mirr` | CI fails on every push (signed guard lowering not yet supported) |
| 6 | 100 formatting diffs accumulated — `cargo fmt` never enforced pre-push | Every commit risks CI failure |
| 7 | `rustfmt.toml` uses nightly-only `normalize_doc_attributes` | Silent behavior difference between local and CI |
| 8 | Rustdoc `<op>` in doc comments treated as HTML tags | `cargo doc` fails with `-D warnings` |
