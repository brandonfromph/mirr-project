# Phase 3 RTM Review — Meeting Agenda

Purpose
- Review Phase 3 requirements (RTM), confirm owners/verifiers, map hazards, and agree acceptance criteria and estimates.

Logistics
- Duration: 60 minutes
- Required attendees: Product Lead, Architect, Compiler Lead, Runtime Lead, Verification Engineer, Test Lead, Release Manager, Tech Writer
- Pre-meeting artifacts: docs/phase3_plan.md, docs/requirements_rtm.md, docs/phase3_hazard_analysis.md, docs/phase3_tasks.md, docs/phase3_task1_actions.md

Agenda
1. Introductions & objectives (5m)
2. Phase 3 summary and scope (5m)
3. Walk each PH3-REQ (20m)
   - Confirm Owner, Verifier, Acceptance Criteria, Verification Method
   - Note needed tests/fixtures and estimates
4. Map HA entries to PH3-REQ rows (10m)
5. Action items and open issues (10m)
   - Create GitHub issues for each PH3-REQ
   - Assign interim owners if unavailable
6. Schedule follow-ups and sign-off criteria (10m)

Meeting outputs (to capture)
- Updated docs/requirements_rtm.md with confirmed Owner/Verifier and estimates
- GitHub issues created and linked in RTM notes
- Agreed acceptance thresholds for determinism/throughput
- Assigned owners for each HA entry

Pre-meeting checklist for attendees
- Read docs/phase3_plan.md and docs/requirements_rtm.md
- Prepare suggested estimates and verifiers
- Identify any missing tests or fixtures

Post-meeting actions
- Publish meeting notes to docs/meetings/phase3_rtm_review_notes.md
- Update RTM verification statuses for items in progress
- Create PRs/issues for immediate action items
